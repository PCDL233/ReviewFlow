## 四、M2 模型运行时

- **AI SDK transport 默认**：`llm.runtime='ai-sdk'`；`http` 保留兼容回退；Anthropic/OpenAI-compatible 分派。
- **调用审计**：`llm_calls` 每次尝试一行；trace 与 `/api/admin/llm-calls` 可查。
- **ReAct 工具**：`read_file`、`list_symbols`、`search_repo`、`symbol_refs`；路径越界拒绝、单次读取限 200 行/60k 字符、`stopWhen(6)`。
- **工具超时**：`review.toolTimeoutMs`（默认 10s），超时按工具错误返回模型。
- **工具字符预算**：`review.toolCharBudget`（默认 120k），同一次审查的工具输出累计计数，耗尽后返回“预算已用完”，防止上下文被工具撑爆。
- **节点检查点**：`review_stages` 记录每个节点起止/耗时/摘要，trace 返回 `stages`；报告页展示节点耗时。
- **结构化输出**：`llm.structuredOutput`（默认关）开启后走 AI SDK `generateObject`，模型只填问题字段，agent/origin/误报由平台注入；有 ReAct 工具时自动回退文本模式。
- **自动续跑**：`SqliteCheckpointSaver`（迁移 v9）持久化 LangGraph checkpoint；`review_jobs`（迁移 v10）记录运行中任务；网络/超时/限流错误同进程重试一次，进程重启后 `resumeInterrupted` 用同一 thread_id 从最后成功节点继续；启动时清理 7 天前且不属于运行中任务的 checkpoint。
- **未完成**：无（单实例部署假设；多实例需分布式锁）。

## 五、M3 人工闭环

- `PATCH /api/findings/:id`：状态 + 误报（`false_positive` 自动同步）。
- `GET/POST /api/findings/:id/comments`：评论。
- `POST /api/reviews/:id/decision`：approve/request_changes/comment。
- `GET /api/reviews/:id/compare?baseId=`：按指纹输出 added/resolved/persisting。
- 前端：发现状态下拉、评论抽屉、决策按钮与标签、对比历史弹窗。
- `GET /api/reviews/:id/decisions`：append-only 决策历史（迁移 v8）。
- `GET /api/stats/rules`：按 `ruleId` 聚合命中数/严重度/误报数（最多 50 条）。
- `POST /api/reviews/:id/pr-comment`：使用 `GITHUB_TOKEN` 将 Markdown 回写到 GitHub PR 评论（可选 `GITHUB_API_BASE`）。
- **未完成**：无（M3 范围内）。

## 八、残余风险

1. **自动恢复的单实例假设**：`review_jobs` + SQLite checkpointer 可恢复单进程中断；多实例同时启动会重复恢复，需要分布式锁/主节点选举。
2. **`review_stages` 无外键**：节点在 reviews 行落库前写入；删除审查时显式清理，启动时 `pruneOrphanReviewStages` 兜底清理崩溃残留。
3. **ReAct 成本**：工具调用增加轮次与 token，需结合 `llm_calls` 观察。
4. **HTTP 运行时无工具**：`llm.runtime='http'` 时 ReAct 不生效。
5. **M5 数据边界**：fixture 来自本地 0.8B 模型，云端模型需用同一脚本重新录制；不将其等同于云端效果。
